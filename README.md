# Hugo Web Studio

Webbplats för Hugo Web Studio – hemsidor för småföretag. Ren HTML, CSS och JavaScript, inget byggsteg.

- `index.html` – startsida (tjänster, demoprojekt, om mig, kontakt)
- `pizzeria.html`, `barber.html`, `butik.html` – demoprojekt (påhittade verksamheter)
- `style.css` – gemensam stil · `script.js` – hero-exempel och kontaktformulär

Öppna `index.html` i webbläsaren eller publicera via GitHub Pages.
